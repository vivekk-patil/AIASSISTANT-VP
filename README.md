# 🤖 AI Personal Assistant

A smart AI-powered web application built with Flask and Groq AI that can answer questions and summarize emails instantly.

## 🌐 Live Demo

https://aiassistant-vp.onrender.com/

## ✨ Features

* 💬 AI Chat Assistant powered by LLaMA 3.3 70B
* 📧 Email Summarization (2–3 sentence summaries)
* ⚡ Fast responses using Groq Inference API
* 🌐 Responsive web interface
* 🚀 Deployed on Render
* 👨‍💻 Custom footer and project branding

## 🛠️ Tech Stack

* Python
* Flask
* Groq API
* HTML
* CSS
* JavaScript
* Render
